# Gardens & Ruins

A personal website built with Astro, designed as a lightweight, content-driven publishing platform for essays, photography, and illustrations.

## Colophon

This site is powered by Astro 7 and TypeScript, with content authored in MDX and structured through Astro content collections. The project uses Sass for styling, plus ESLint, Prettier, and Stylelint to keep the codebase clean and consistent.

### Engine and framework

- Astro 7
- TypeScript
- MDX for structured content
- npm scripts for development, linting, formatting, and production builds

### Styling and typography

- Sass for stylesheet organization
- EB Garamond Variable for editorial serif headings and body text
- Inter Variable for supporting sans-serif UI and secondary text

### Content and integrations

- Astro content collections for posts and pages
- Vercel Analytics and Speed Insights

### Hosting

- Hosted on Vercel

### Project scripts

- `npm run dev` — start the local development server
- `npm run build` — run linting, formatting checks, type checking, and production build
- `npm run preview` — preview the production build locally

## Notes

The website is intentionally simple and fast: static pages, semantic HTML, modern typography, and a clean asset pipeline. The implementation is designed to be easy to maintain while preserving a polished editorial feel.
